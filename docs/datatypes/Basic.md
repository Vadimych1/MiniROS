# Basic datatypes
These built-in types are used with native Python `bools`, `ints`, `floats`, `strings` and `bytes` or `bytearrays`. They don`t have an own constructor

# Bool
Handles boolean value

# Int
Handles one 32-bit signed integer (from `−2 147 483 648` to `2 147 483 647`)

# UInt
Handles one 32-bit unsigned integer (from `0` to `4 294 967 295`)

# Float
Handles one 32-bit float

# String
Handles string of unlimited size

# Bytes
Handles bytes of unlimited size
